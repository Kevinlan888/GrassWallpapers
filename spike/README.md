# 草地动态壁纸

这是仓库中唯一维护的动态壁纸。启动器入口只负责打开设置页；
Vulkan 渲染在系统壁纸服务中启动。

- 包名：`com.a65.grasswallpapers.vulkan`
- 版本：`0.11`（`versionCode 11`）
- 最低 Android：7.0（API 24）
- 目标 Android：15（API 35）
- ABI：`arm64-v8a`、`armeabi-v7a`

## 使用方式

点桌面图标会打开壁纸设置页，再点“设为动态壁纸”进入系统预览。
部分启动器只暴露系统壁纸列表，可从设置页的第二个按钮进入。

`0.11` 修复了切换预览后旧 Engine 误停全局渲染器、导致桌面画面停滞的问题。
现在每个 Engine 持有独立 Owner ID，只有当前 Owner 能停止、暂停或调整渲染器。

`0.10` 已补齐应用图标、动态壁纸缩略图和 `WallpaperService`。启动器页面不会直接
初始化 Vulkan，因此点击图标不会再进入旧的 SurfaceView 测试渲染路径。
同时修正了 Android 15 上启动页在 DecorView 创建前查询 InsetsController 导致的闪退。

## 场景内容

`0.11` 包含：

- 512 片六段弯曲草叶，按季节改变高度、颜色、风力和冬季霜色
- 18 株蒲公英，茎和白色绒球使用连续时间运动，不依赖逐帧随机数；
  更大、更饱满的绒球由多层柔细纤维、棉絮核心和羽状尖端组成
- 96 个季节粒子：春花瓣、夏羽绒感蒲公英种子、秋枫叶、冬雪
- 冬季蒲公英植株与绒球完全淡出，只保留雪花，不再出现残留蒲公英
- 清晨、白天、傍晚、夜晚四套天空渐变、星空和光照，不绘制太阳或月亮
- 北半球按本地月份自动选择春、夏、秋、冬，按本地时钟自动选择时段
- 应用内可关闭“跟随本地时间与季节”，改为按 30 秒、1 分钟、5 分钟或
  15 分钟轮转；每个时段轮换一次，走完四个时段后进入下一季
- 动态壁纸设置通过共享偏好即时同步到正在运行的壁纸，无需重新应用

关闭“跟随本地时间与季节”后，桌面支持触摸切换：轻点左半屏切换季节，
右半屏切换时段。开启时间同步时，触摸切换会被屏蔽，避免画面被误改。
壁纸不可见时会暂停渲染线程，回到桌面后继续。

渲染继续优先使用 4x MSAA。若设备没有 Vulkan，壁纸服务不会闪退，但无法绘制场景；
可查看 `VulkanGrassWallpaper` 日志中的错误行。
